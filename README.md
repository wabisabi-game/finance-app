# マーケット道場

金融ニュースを読み解き、金融就活の面接でマーケットを語れるようになるための個人用学習Webアプリ。
要件定義書のMVP（用語辞書・デイリークイズ・マーケット日記・進捗）を実装している。

## 使い方

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ロジックとコンテンツの検証
npm run build    # 型チェック＋本番ビルド（dist/）
npm run preview  # ビルド結果の確認（PWA・オフライン動作はこちらで確認）
```

## 機能

| 画面 | 内容 |
| --- | --- |
| ホーム | 今日のタスク、連続日数、答え合わせ前の日記への導線 |
| クイズ | 1日10問（新規3＋復習7）。4択・○×・因果問題。途中で閉じても続きから再開。分野別・ランダム・用語別の自主演習 |
| 辞書 | 日英の部分一致検索、分野フィルタ、覚えたフラグ |
| 日記 | 6指標の終値と前日比、ニュース、自分の説明、確信度、答え合わせ、タグ、検索、2分説明タイマー。入力は自動保存 |
| 財務分析ドリル | 架空の会社の財務三表（PL・BS・CF）から、ROIC・ROE・FCFなど14指標を計算する。5問ごとに会社の状態を目安で診断 |
| 進捗 | 連続日数、分野別正答率、苦手用語トップ10、ドリルの指標別正答率、日記のヒートマップ |
| 設定 | 1日の出題数、テーマ、JSONエクスポート／インポート |

間隔反復：デイリークイズで正解するたびに次の出題を 1→3→7→14→30日後に延ばし、不正解で1日に戻す。
自主演習は正解しても間隔を延ばさない（不正解なら1日に戻す）。

## コンテンツの追加

`content/terms/*.json` と `content/questions/*.json` を編集するだけで反映される（ファイルを増やしてもよい）。
形式は `src/types.ts` の `Term` / `Question` を参照。`npm test` が次を検証する。

- id の重複、関連用語・問題のリンク切れ
- 一言説明が50字以内、1語につき2問以上、正解番号が選択肢の範囲内

4択・因果問題の選択肢は表示時にシャッフルされるので、`answerIndex` の位置は気にしなくてよい。

**裏取りについて**：現在の用語・問題はAIが下書きしたもので、出典での確認は済んでいない。
`source` には確認先の候補を書いてある。確認が済んだ用語に `"verified": true` を付けると、
用語詳細の「裏取り前」表示が消える。

## データの保存

学習記録と日記は端末のブラウザ内（IndexedDB）にのみ保存される。スマホとPCの間では同期されないので、
設定画面のエクスポート／インポートで移す。

## デプロイ

**GitHub Pages**：リポジトリの Settings → Pages → Source を「GitHub Actions」にすると、
プッシュのたびに `.github/workflows/deploy.yml` が `https://<owner>.github.io/finance-app/` へデプロイする。
非公開リポジトリでPagesを使うには有料プラン（GitHub Pro など）が必要。

**Vercel**：リポジトリをインポートすればそのまま動く（Framework: Vite、出力先: `dist`）。

どちらも検索エンジンに載らないよう `noindex` を指定している。ただしURLを知っていれば誰でも開ける。
iPhoneではSafariの共有メニューから「ホーム画面に追加」。

## デザインの決まり

色・余白・文字は `src/index.css` のトークンで一元管理している。画面側では `bg-surface` `text-sub` のような役割名で使う。

- ブランド色は藍（accent）。緑と赤は「正解・不正解」「上昇・下落」の意味を伝えるときだけ使う
- 面の区切りは枠線ではなく、背景色の差と淡い影で付ける。ダークでは面を一段ずつ明るくする
- 日本語に合わせて行間を広め（本文1.75）に取り、見出しは `palt` で約物を詰める
- 文字のコントラスト比は4.5:1以上、押せる要素は高さ44px以上
- 動きは短く控えめに。端末の「視差効果を減らす」設定では止まる

## 構成

```
content/            用語と問題のJSON（読み取り専用の同梱データ）
src/lib/            srs（間隔反復）、db（IndexedDB）、stats、backup など
src/pages/          各画面
src/components/     レイアウト、クイズ実行、2分タイマー
tests/              間隔反復・集計・バックアップ・コンテンツの検証
```
